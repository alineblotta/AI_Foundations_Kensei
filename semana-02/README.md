# Semana 02: Fundamentos de Python e Vibe Coding

Este repositório documenta as atividades da segunda semana da **Kensei Cyber AI Academy**. O foco foi a consolidação dos fundamentos de Python, utilizando a metodologia **Vibe Coding** — onde a IA atua como um copiloto técnico para a escrita e o entendimento do código.

## 📁 Estrutura do Repositório
* **`/exercicios`**: Implementações diretas baseadas no material didático para a prática de sintaxe e lógica básica.
* **`/projetos`**: Scripts desenvolvidos para aplicar os conceitos em cenários práticos, com evoluções autorais focadas em defesa e automação.

### **Destaque do Projeto Extra: Kensei CyberSec Pathfinder (`carreirascyber.py`)**

O *Pathfinder* é um motor de recomendação de trilhas de carreira em Cibersegurança que desenvolvi para automatizar a orientação de estudos.

* **O que faz:** Funciona como um consultor interativo que mapeia o perfil e os interesses do usuário.
* **Funcionalidades:**
    * **Diagnóstico:** Questiona afinidades técnicas (Red Team, Blue Team, DevSecOps, etc.).
    * **Mapeamento Lógico:** Utiliza estruturas de decisão (`if/elif/else`) para filtrar e recomendar a trilha ideal.
    * **Roadmap:** Exibe competências críticas necessárias para a trilha escolhida.

---

## 🧠 Metodologia: Vibe Coding
O desenvolvimento seguiu o fluxo de **Pedir > Ler > Rodar > Iterar**, priorizando a compreensão da lógica acima da memorização:

1. **Pedir:** Descrição de requisitos funcionais para a IA.
2. **Ler:** Análise crítica do código gerado para garantir a compreensão total.
3. **Rodar:** Execução em ambiente local para validação funcional.
4. **Iterar:** Refinamento do código com camadas adicionais de segurança ou melhorias de fluxo.
